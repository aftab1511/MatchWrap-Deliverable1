About MatchWrap

MatchWrap is a dedicated post-match football platform designed to provide fans, analysts, and moderators with structured match summaries, player ratings, and detailed event commentary.

Deliverable 1 Scope

This project is implemented as part of the Web Technologies course requirements. Deliverable 1 focuses purely on standard front-end static layout structure using clean HTML5 markup and Bootstrap 5 components prior to MVC backend integration.
